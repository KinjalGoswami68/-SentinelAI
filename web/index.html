How it works

01

Detect

Each answer is embedded and compared with the bot's own normal answers. Plain math (nearest neighbours and CUSUM), no LLM, no cost per answer.

02

Investigate

Code compares the numbers, clusters the changed answers and lines up version changes. Then one LLM call writes the note, and every claim must cite those results by id.

03

Alert

Signals become one incident, with at most 3 Slack messages: opened with the note, escalated, resolved.

What it can't do

  • It does not check facts. It notices when answers change, not whether an answer is true.
  • On-topic changes without version metadata are hard. If the bot doesn't send prompt_version or model_version, the note can often only say "something changed".
  • A change during learning is learned as normal. The first answers become the baseline, mistakes included.
  • A topic it never saw while learning gets flagged. That is a real change for the bot, but it may be one you expected.
  • Free tier, so it is slow to wake. The server sleeps outside 09:00–21:00 IST and the first request takes about a minute.
